## 5. Classification par âge (onglet « Classification par âge »)

Répondez **Aucun / Non** à toutes les questions de contenu (violence, peur, langage, sexualité, jeux d'argent, etc.).
- Contenu généré par les utilisateurs, messagerie, accès Web illimité : **Non**

Résultat attendu : **4+**.

Avec une classification 4+, réglez AdMob pour que les pubs restent tout public :
AdMob › Paramètres de blocage › **Classification maximale du contenu des annonces : G** (tous publics).

## 8. Ce qui reste à faire avant de soumettre (dans cet ordre)

1. Contrat **« Apps payantes »**, banque et impôts dans App Store Connect › Accords, taxes et services bancaires.
2. Créer les 3 produits Mozaik+ (voir `MONETISATION.md`), puis RevenueCat, et m'envoyer la clé `appl_…`.
3. Je prépare le **build 2** : clé RevenueCat, pubs réelles (`testing: false`) et vrai lien App Store dans le partage.
4. Sélectionner le build 2 dans la version 1.0, puis **Soumettre pour vérification** (je vous demanderai votre accord).
